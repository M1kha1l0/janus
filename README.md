# janus
Janus — высокопроизводительный прозрачный сетевой шлюз. Автоматически выявляет заблокированные сайты через анализ TLS SNI и бесшовно перенаправляет трафик в туннель без   ошибок соединения для клиента. Ведёт самообучаемый кэш доменов, не требует настройки клиентских устройств и установки сторонних SSL-сертификатов.
